Connect Google Calendar

Two-way sync: events you add here go to Google, and events you add in Google show up here. Your events only load after you sign in, so nobody else visiting the site can see them.

One-time setup (about 10 minutes). Google needs you to create a free “client ID” that lets this site ask for your permission.
  1. Open Google Cloud (sign in with the Google account that has your calendar) and create a project called Brain 2.
  2. Turn on the Google Calendar API for that project (click Enable).
  3. Open Google Auth Platform → Get started. App name Brain 2.0, your email, audience External. Then under Audience → Test users, add your own Gmail address.
  4. Go to Clients → Create client → type Web application. Under Authorized JavaScript origins add → Create, then copy the Client ID.
  5. Paste it below and press Connect. Google will say it “hasn’t verified this app” — that’s expected for your own private app: click Continue.
