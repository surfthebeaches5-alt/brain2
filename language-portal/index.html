Import words
Bring an Anki deck (.apkg, audio included), a text export, a CSV, or just paste a list. Duplicates (same front) are skipped.
Get a deck from AnkiWeb (no Anki app needed)
  1. Open AnkiWeb Shared Decks and find a deck.
  2. Click Download. You get an .apkg file with the deck’s audio and pictures inside.
  3. Drop the .apkg here, pick which fields go on the front and back, and import.
Exporting from Anki desktop instead
  1. Open Anki → Browse, pick your deck on the left.
  2. Either File → Export… as Anki Deck Package (.apkg) with “Include media” ticked (keeps audio),
  3. or select the cards → Notes → Export Notes… as Notes in Plain Text (.txt) (text only).
  4. Drop the file here.
