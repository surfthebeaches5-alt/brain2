How to export from Anki
  1. Open Anki → Browse, pick your deck on the left.
  2. Select the cards (Ctrl/Cmd+A) → Notes → Export Notes…
  3. Format: Notes in Plain Text (.txt). Untick “Include HTML and media references” if you like.
  4. Drop the .txt file here.
