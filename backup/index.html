Backup & Restore

Everything you enter in Brain 2.0 lives inside this browser on this device. Export it to a file to keep it safe, move it to another device, or carry it to a new home for the site.

Export

Bundles every Brain 2.0 record on this device into one file and downloads it. Do this from the device that has your data.

Import

Loads a backup file into this browser. Use this on a new device, after a cache wipe, or on a new address for the site.

How restoring works: importing writes each section from the file into this browser. If a section already exists here and in the file, the file's version replaces it — so import onto a fresh device, or export a safety copy from this device first. Sections that exist only on this device are left untouched.
